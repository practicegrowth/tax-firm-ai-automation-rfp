# Contributing to the Tax Practice AI & Automation RFP Template

Thank you for your interest in improving this resource. Contributions from tax professionals (EAs, CPAs, tax attorneys), technology evaluators, and AI practitioners help keep this template accurate and useful for the entire tax practice community.

## How to Contribute

### Reporting Issues

If you find outdated information, missing evaluation criteria, or have suggestions for improvement:

1. Open an issue on this repository
2. Describe what's wrong or what's missing
3. Include your reasoning and, if possible, a reference to a primary source (IRS publication, Circular 230 section, etc.)

### Suggesting Changes

1. Fork the repository
2. Create a feature branch (`git checkout -b improvement/your-suggestion`)
3. Make your changes with clear, specific language
4. Submit a pull request describing what you changed and why

### What We're Looking For

- **Updated evaluation criteria** reflecting new AI capabilities or compliance requirements (especially Circular 230 updates)
- **Additional checklist items** for emerging AI categories (e.g., agentic AI, multi-modal models, credential-aware AI)
- **Implementation roadmap refinements** based on real tax practice deployment experience
- **Corrections** to outdated technical claims or vendor landscape shifts
- **New sections** addressing gaps (e.g., state-specific tax practice regulations, multi-state compliance)
- **Credential-specific guidance** for EA, CPA, and tax attorney practices

## Contribution Guidelines

- **Be specific.** Vague suggestions are hard to act on. Include concrete language where possible.
- **Cite sources.** If you're adding an evaluation criterion or technical requirement, reference why it matters (IRS publication, Circular 230 section, state tax board rule).
- **Stay neutral.** This is a vendor-neutral resource. Don't add vendor-specific recommendations.
- **Consider the audience.** Tax practice decision-makers range from technology-savvy to technology-averse. Write for both.
- **Respect compliance.** Tax practices are governed by Circular 230, state tax board rules, and IRS regulations. Ensure suggestions comply.
- **Understand credentials.** EA, CPA, and tax attorney are distinct credentials with different scopes. Don't conflate them.
- **One change per PR.** Keep pull requests focused on a single improvement.

## Review Process

1. A maintainer will review your PR within 7 days
2. We may ask clarifying questions or request changes
3. Accepted changes are merged and the "Last Reviewed" date is updated
4. You'll be credited in the commit history
